# PowerDuels logo kit

Write **PowerDuels** in UI copy and metadata, one word. The stacked logo reads **POWER / DUELS**. A gold power-up badge, bolt, four sparks, and lightly tilted letterforms keep the approved gold-and-cream identity and give it more arcade energy.

| Asset | Use |
| --- | --- |
| `powerduels-logo-sheet.png` | Visual overview of the complete mark, compact badge, horizontal logo, monochrome bases, and color values |
| `powerduels.psd` | 2000 × 820 layered master, with Lobby Gold and black/white base groups |
| `powerduels.svg` and `powerduels.png` | Editable color master and transparent 2000 × 820 export |
| `powerduels-horizontal.svg/.png` | Horizontal logo for shorter spaces |
| `power-badge.svg/.png` | Standalone bolt badge, 1024 × 1024 transparent PNG |
| `base-white.svg/.png`, `base-black.svg/.png` | Flat, single-ink bases for recoloring or high contrast |
| `ui/` | 1000 × 410 transparent and aligned POWER, DUELS, sparks, full mark, and shine mask |
| `powerduels-reveal.gif` | Motion preview on charcoal |

The logo uses Lobby Gold `#FFD23F`, Warm Light `#FFF6DF`, Amber `#E48E28`, and Ink `#211A22`. The lettering is based on Lilita One and outlined in the SVGs. In the PSD, separate layers hold the badge face, depth, glint, POWER lettering, bolt, DUELS faces and depth, and sparks.

The reveal brings POWER in from the upper left by 235 ms. DUELS enters around 185 ms and rises into place by 500 ms. Sparks appear from 340 ms. Reduced motion uses a fade of `ui/full.png`. The 1000 × 410 image bounds, including clear padding, align every sprite.
