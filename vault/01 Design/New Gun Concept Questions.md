# New gun concept questions

Use one copy of these questions per original Gauntlet gun. Start with the first gun in the batch. Working names, rough ideas, and references are enough for the first pass.

## Batch

1. How many guns are in the batch, and which one goes first?
2. Do they share an art or effects theme, or should each have its own identity?
3. Are any older Gauntlet concepts coming back? If so, which parts of the old idea should carry forward?

## Per gun

| Area | Questions |
| --- | --- |
| Gameplay role | What class or slot is it? Where should it fit in the current roster? What should it do better than the closest stock gun, and what tradeoff keeps both worth using? |
| Signature mechanic | What does the player do, and what happens in the game? Is the signature an alternate input, a conditional effect, or part of the regular firing loop? How can another player see it coming or respond? |
| Silhouette and finish | What should it look like in one sentence? Which shapes identify it at a glance and from first person? What palette, finishes, and references fit it? |
| Effects | What are the key beats for anticipation, activation, impact, and fade? What should the user and other players each see? Which effects carry gameplay information, and which are cosmetic? |
| Audio | What should the signature sound like? Which cue signals the effect is about to happen, and which confirms it happened? |
| Animation | Which poses or beats need bespoke work? Consider equip, idle, aim, fire, reload, inspect, and any alternate action. Pick the one moment the first sheet needs to communicate. |
| Readability | What should stay clear at the crosshair and at a distance? How should the effect hold up on bright and dark maps or when several players use it at once? |
| First prototype | What should a Gauntlet Studio playtest prove? Which features can wait until that test works? |

## Concept deliverables

- **Model sheet** with a large front-left three-quarter view, side and top views, a first-person view, palette swatches, and details that explain the new silhouette.
- **Effects and pose sheet** with the main timing beats, the first-person and other-player reads, and any signature pose or animation needed to explain the design.

Use [Gun Balance](Gun%20Balance.md) for the current roster and phase context. The [archived modeling briefs](Archive/Gauntlet_Weapon_Modeling_Briefs.md) provide examples of the level of detail for a Blender handoff.
