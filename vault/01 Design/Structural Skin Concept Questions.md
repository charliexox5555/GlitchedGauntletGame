# Structural skin concepts

Round one covers six original Gauntlet skin lines, reviewed one at a time in this order. The VALORANT collection names identify the references.

1. [Hivemind](https://wiki.playvalorant.com/en-us/Hivemind_Collection)
2. [Intergrade](https://wiki.playvalorant.com/en-us/Intergrade_Collection)
3. [SilkLeaf](https://wiki.playvalorant.com/en-us/SilkLeaf_Collection)
4. [Orion](https://wiki.playvalorant.com/en-us/Orion_Collection)
5. [Ruin](https://wiki.playvalorant.com/en-us/Ruin_Collection)
6. [Endeavour](https://wiki.playvalorant.com/en-us/Endeavour_Collection)

These are cosmetic variants of the current roster. Each line can reshape the visible shell and use original materials, surface patterns, and restrained animation. Keep the gameplay behavior and sight alignment of the host gun. Review reference images for shape language and finish, then create original names, forms, and graphics. Make moving textures or a small inspect detail earn their place in the concept.

Pair each cosmetic with the original Gauntlet gun renders. Keep the stock gun's overall size, recognizable proportions, and first-person coverage close. Allow modest changes in thickness and taper. Use concept images for styling, then verify dimensions and ADS against the stock Blender model and the live Studio aim view.

## Questions for each line

- **Reference read** — Which shapes, materials, and details make the reference recognizable? Which details should Gauntlet reinterpret?
- **Identity** — What is the original name and the visual idea in one sentence? What do players recognize at normal first-person size?
- **Roster** — Which current gun should anchor the line? Which guns deserve a variant, and what does the design gain on each? Does the line also suit a melee variant?
- **Structure** — Which visible surfaces change shape? How does the treatment adapt across the roster while keeping each gun identifiable and clear in first person?
- **Motion** — Does the finish need an animated texture or a small inspect detail? Where does it live, when does it move, and how does the skin read at rest?
- **ADS** — Is a custom cosmetic sight frame worth drawing? Show the aim view if so, with stock sight alignment and an equally clear sight window.
- **Ammunition** — Would a custom visible cartridge, shell, or casing finish help sell the line during inspect or reload? Treat it as presentation and keep shot behavior stock.
- **Buddy or charm** — Would one matching accessory add anything? Sketch it and its mount if useful. Integration can follow later.
- **Concept sheet** — Start with the hero’s three-quarter, side, top, and first-person views, plus swatches. Add detail panels only for approved changes such as an ADS frame, finish motion, visible ammunition, or a charm.
