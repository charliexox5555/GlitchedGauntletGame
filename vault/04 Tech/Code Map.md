# Code Map

One line per module: what it owns, its remotes and state fields. **Use it to pick the files a code task needs, then `Grep` for the symbol and `Read` a line range. Don't open whole files.** Rules and the shot/match walkthroughs: [Architecture](Architecture.md). Generated 2026-11-07 from the file headers and `Net.luau`; if a module changed a lot, trust the file and fix this line.

Layout: `src/shared` (ReplicatedStorage.Shared), `src/server` (match place server), `src/client` (match place client), `src/lobby/{server,client,shared}` (Lobby place). Sizes in lines are rough.

Lobby remotes (`src/lobby/shared/LobbyNet.luau`, folder `LobbyRemotes`): `QueueRequest` (client → server: `join`, mode / `leave`), `QueueEvent` (server → client: found / failed / studio / info), `PartyRequest` (client → server: `invite` / `accept` / `decline`, userId; `leave`), `PartyEvent` (server → client: invite / info), `LockerRequest` (client → server: `equip`, gunId, line), `ShopRequest` (client → server: `buyCase`, caseId / `devCoins`), `ShopEvent` (server → client: bought / opened / refunded / coins / failed), `CaseShow` (server → other players: someone's opening to play).

Every handler uses `Util/Validate` (types, finite numbers) and `Util/RateLimit` (token buckets from `Config/Combat RATE`, `Config/Mods RATE`).

## Shared state

- **Storage contract** — [State Values and Asset Data](State%20Values%20and%20Asset%20Data.md). `Shared.StateValues` reads runtime values and ModuleScript defaults. `Simulation/Fields` lists the values prepared before a character can be stepped. Historical Attribute field names below refer to their current value or module field.
- **Skin preview** (`shared/Config/SkinPreview`, `shared/SkinPreview`, `SkinPreviewService`, `SkinPreviewController`): each player picks a skin line for their own guns (F7 / `\` cycle, `;` opens the list). The pick is a **server-set Player attribute** `PreviewSkinLine` (starts Stock); the `PreviewSkinLine` remote takes an allowlisted line name (type and length checked, `Util/RateLimit` 1/s burst 3, `canUse`). Runs in the match place 133387545285290, in Studio; live servers only for `Config/SkinPreview.USER_IDS` (empty = nobody since skins are owned, 2026-11-20). Camera guns follow their viewer (or the spectated player; the final-kill replay wears the killer's skins through `ViewmodelController.setSubject(copy, owner)`; bots stay stock; owner in the camera model's `SkinOwnerId`), world guns follow the character holding them (server). Immutable `Weapons` stock templates and `WeaponSkins/<Line>/<Id>` variants; missing variants fall back to stock. The F7 pick is a dev tool; real skins are owned (`shared/PlayerData` `skins`) and `SkinPreviewService` publishes only owned Locker equips (fail closed). `client/Util/ChamberFlow` (started by `SkinPreviewController`): on camera guns only, drifts the two flow `Texture` layers tagged `MoltframeFlowLayer` on structural-skin chamber parts and pulses the chamber `SurfaceAppearance.Color` (`Config/SkinPreview.CHAMBER_FLOW`); world models keep the static map. Installer for geometry skins: `tools/studio/InstallMoltframeSkin.luau` (Decal -> Image id resolve).
- **Locker skins** (`shared/Locker`) saves one equipped line per gun via the Lobby's `LockerService` and DataStore `LockerV1`. Both places publish a JSON `LockerSkins` value on the player. `SkinPreview.line(player, gunId)` uses that value when the F7 preview is on Stock. Matchmaking and returns carry their join details through `TeleportData`.
- `tools/studio/InstallFlatSkin.luau`: Studio-edit installer for flat-material geometry skins (one MeshPart per material from `tools/blender/export_roblox_flat.py`, tiled pattern Textures, kept stock parts in the line finish) into `WeaponSkins/<Line>/<Gun>`; `InstallMoltframeSkin.luau` now takes `line` too.
- Whole skin lines: `tools/blender/export_skin_items_flat.py` (per item: flat FBX + `manifest_flat.json` with replaced stock prefixes, extra rig joints, the line Vandal's palette) → `tools/studio/make_flat_install_jobs.py` stages `InstallFlatSkin` + jobs in a temporary Rojo folder `src/shared/_SkinInstall` (remove with `--clean`). Knife-slot skins install as `WeaponSkins/<Line>/Knife` with attribute `SkinItem` (Fan / Blade / Dagger).
- Skin casings: `client/Util/ShellFx` throws `WeaponSkins._Casing` (CasingBody + CasingBand, Studio-owned) coloured by `shared/Config/SkinCasings` when the gun model's `SkinLine` has an entry; else the stock brass shell.
- **Slide lean** (`client/Util/SlideTilt`, 2026-11-20): one spring stepped at `RenderPriority.First` (`Juice.SLIDE` rollIn* in, rollSpeed/rollDamping out). `CameraController.setRoll` drives it; the camera roll, `Util/Crosshair` tilt (and the hit marker through `Crosshair.tilt()`), the `ScopeOverlay` reticle and the viewmodel cant (`VM.SLIDE_CANT`, in `ViewmodelController` at the root) all read `SlideTilt.amount()`, so they stay in the same frame.
- Gun clips (`client/Util/GunAnimator`, viewmodel and third-person): a monotone cubic (PCHIP) between the 24 fps keys; bones whose Fire clip starts off the built pose rest there (the Marshal hammer). Scoped guns fade `ScopeLens` early in the aim (`VM.SCOPE_LENS`). Re-key one gun's clips headless with `tools/blender/rekey_clips.py`.
- Hiding viewmodel parts: `client/Util/LocalHide.set(part, value)` sets `LocalTransparencyModifier` on the part **and its Textures/Decals** (skin patterns); used by `ViewmodelController` (scope hide, mags, carried rounds, props, ADS fade), `ViewmodelHeldMods`, `WeaponController` (own third-person gun). `MagDrop` fades a dropped mag's Textures with it.
- Skin export checks: `tools/blender/export_roblox_flat.py` keeps `*Sight*` objects as `SK_<Bone>_Sight_NN` parts (the ADS occluder fade skips names with "Sight") and lifts flush coplanar faces (`resolve_coplanar`, 0.004 studs) and splits self-crossing faces (`fix_crossed_faces`). `tools/blender/check_flat_export.py` re-imports exported FBXs and renders them one-sided on magenta (what Studio draws). Shell-kit outlines use `model_vandal_shell_base.convex_hull_xz` (never Blender's `convex_hull_2d`). Pitfalls and checks: `vault/02 Art/Skins/Skin Build Pitfalls.md`.
- **Shadow Mist idle** (`Config/SkinPreview.SHADOW_MIST`, `client/Util/ShadowMistIdle`): the Studio-only RuinBlighted preview line uses 33 body motors and eight radial rear-sight motors under the Vandal Root. The flat-skin manifest owns the motor tags, emissive groups and effect anchors. `ViewmodelController` steps the effects after `GunAnimator` and before the rig solve. Six smoke emitters and close seafoam lights follow the gun. ADS tapers the smoke and reduces body travel while the lit aperture fragments keep moving. Magazine light and smoke follow magazine visibility.
- **Shadow Mist ammunition** (`tools/blender/build_shadow_mist_magazine_rounds.py`, `client/Util/ShadowMistActions`, `Config/SkinCasings`). The full cartridge is part of the moving magazine. The flat installer tags it `SkinLoadedRound`, and the reload hides the cartridge on empty magazine drops. `ShellFx` uses the shared `_Casing` geometry and RuinBlighted finishes for ejection. `TracerFx` draws the in-flight mist and `ImpactFx` owns the brief spectral flash and wall scorch.
- **Ruin-Blighted expansion** (`Config/RuinBlightedPresentation`, `Config/Viewmodel`, `client/Util/ShadowMistActions`, `client/Util/RuinedReaver`). Gun profiles stage the support-hand cast and inspect. The viewmodel aligns the reload pose to release and seat while the cast ribbon follows the mag. The `SkinItem` marker on the Knife-slot model selects the Reaver's first-person two-hand poses. Its spectral beams join paired sockets on the moving blade. The Guardian's exported sight sockets attach the shared aperture beams to the actual fracture segments. `SkinAdsDistance` sizes the aperture in the camera while weapon config owns gameplay FOV. The shared Knife heavy attack starts its pose when `WeaponService` accepts a windup. `WeaponController` casts at the animation's contact and sends the result through `Fire`. The server validates the pending windup, reach, cooldown and damage. Light slashes keep instant hit queries. [Expansion ledger](../02%20Art/Skins/RuinBlighted/Expansion%20Ledger.md)
- **Shadow Mist actions** (`client/Util/ShadowMistActions`, `ShadowMistActionFx`): dedicated draw, inspect and reload tracks share their clip clock with the effect accents. Reload starts at the clip's release marker, stages a forming magazine out in the support hand, and drives the throw and seating beats from `Config/SkinPreview.SHADOW_MIST`. `ShadowMistIdle` layers shot flex and a traveling light pulse onto the body shards. `WeaponController` queues a trigger tap through the inspect fade. `EffectsController` selects the Vandal's local layered flash, mist-wake tracer and wall scorch by skin line.
- **Tempest-Strike line** (`client/Util/TempestIdle`, `client/Util/TempestFx`, `client/Util/TempestCoat`, `client/Util/TempestKatana` (the knife-slot Katana: Neon water edge + sheath, ribbons, spine arcs, lights, full-blade trails, Cleave, ring / charm joints; `ViewmodelController` swaps in the `Katana*` screen tracks), `Config/TempestProfiles` (per-gun points, moving parts, tracks incl. shell-reload parts and the Marshal's `cycle`; `fit` guns place rings and the pulse on measured outline stations via `TempestIdle` `hull()`; `TempestIdle.beat` handles clip beats from the viewmodel bump), `Config/SkinPreview.TEMPEST`, `Config/TempestAudio`, Viewmodel tracks `DrawTempest` / `ReloadTempest` / `InspectTempest`): first-person only. `TempestCoat` welds ForceField water copies onto the meshes (before ViewmodelRig). The s08 rig adds Motor6Ds `TS_VentL`, `TS_VentR` and `TS_Crescent` whose Transform `TempestIdle` springs every frame. `TempestIdle` builds its effects on the Root-motor part (they ride recoil, reload and inspect), steps idle water helices, vent arcs and breathing conduits, the reload dissolve / gather / seat, the draw and inspect water ring, and a small Handle-space motion layer (`TempestIdle.pose`, applied to `handleCf`). Its action beats call `TempestIdle.cue`, which plays the `tempest:` foley bank. `EffectsController` picks `TempestFx` (shuriken flash, port jets and mist, cyan strike impact) and the water tracer wake by skin line; `ownImpact` gives own pass-through hits the same strike, and `ImpactFx.impact(..., ownStrike)` skips the orange flash. `ViewmodelController` selects the Tempest tracks when `gun.tempest` exists and replaces the mag drop with the water burst.
- **Slipframe Guardian** (`client/Util/SlipframeEffects`, `ViewmodelController`, `Config/Viewmodel`, `client/Util/MuzzleFx`, `EffectsController`): Studio hero preview. `InspectSlipframe` owns the hold so the stock press-check does not reach over the light. The first-person clone animates `SK_Root_SFInspectPanel` over three recessed contacts, shows a layered upper-chamfer sweep and flashes the receiver at panel seat. Fire also drives the sweep and routes the forked muzzle flash through `EffectsController.localShot`. `MagIn` drives the smaller receiver flash. `ViewmodelRig` solves the moving panel and both sweep layers. World templates use fixed cosmetic welds. [Rework ledger](../02%20Art/Skins/Slipframe/Rework%20Ledger.md#inspect-visibility-and-finish)
- Knife-slot skin motion: `client/Util/FanMotion` (Giltfold Fan ribs: Rib_NN Motor6D Transforms, stepped by `ViewmodelController` after the gun's GunAnimator) with numbers in `shared/Config/MeleeSkins` (`FAN`, `VIEWMODEL_SCALE` by `SkinItem`); Studio scrub `Workspace.DevFanScrub`.
- **Match state** (`shared/MatchState`) uses server-owned JSON StringValues under `ReplicatedStorage.MatchState`. Phases, scores, readiness counts, map options, round history and rematch votes share this folder. Each list updates as a single value. `MatchState.isSpawnHold()` gates movement during Draft and Countdown. `CombatLocked` is a transient player flag.
- **Zone** (`shared/Zone`) publishes one snapshot under `ReplicatedStorage.MatchState.Zone` with the center, radii and server timestamps.
- **Health** (`shared/Health`): Humanoid attributes `HP`, `MaxHP`, `Downed`; written only by `HealthService`.
- **Status effects** (`shared/Mods/Status`, `Config/StatusEffects`): expiry attributes (`HinderedUntil`, …, `StatusStunned`) written only by `StatusService`.
- **Mod loadout on the player**: `Mod<n>Id`, `Mod<n>Level`, `ModUnlimitedCharges`, `ModResetSerial`, `ModHeld`, `ModUseAt`, `ModUseKind`, `ModReject`.
- **Weapon on the player/character**: `WeaponId`, `Aiming`, `AimPitch` (players: the unreliable `Aim` remote at up to 30 Hz with a settle send and a 0.5 s keepalive, `Juice SPECTATE aimSend*`), `AimYaw` (bots only: where the gun points, `Bots/Brain publishAim`, mirrored onto the model by `BotService`), `ReloadAt/For`, `SwingAt/Heavy/Step`, `HitAt`, `LastAttacker`, `FireReject` (Studio, last rejection reason).
- **Test mode** — the Workspace `TestMode` Boolean Attribute controls Studio Play. `shared/TestMode` publishes the resolved mode as a value.

## How to use this map
1. Name the area (e.g. "the Frost burst hurts allies") → find the rows → `Grep -n "symbol" src/...` → `Read` with `offset`/`limit`.
2. Gameplay numbers are in `src/shared/Config/*.luau`, never in the systems: grep the config first.
3. Anything touching a remote: read the owning service's handler and `Util/Validate` use, then the [Architecture](Architecture.md) shot walkthrough.
