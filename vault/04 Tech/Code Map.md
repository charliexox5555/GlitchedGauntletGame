## Shared state

- **Storage contract** — [State Values and Asset Data](State%20Values%20and%20Asset%20Data.md). `Shared.StateValues` reads runtime values and ModuleScript defaults. `Simulation/Fields` lists the values prepared before a character can be stepped. Historical Attribute field names below refer to their current value or module field.
- **Skin preview** (`shared/Config/SkinPreview`, `shared/SkinPreview`, `SkinPreviewService`, `SkinPreviewController`): each player picks a skin line for their own guns (F7 / `\` cycle, `;` opens the list). The pick is a **server-set Player attribute** `PreviewSkinLine` (starts Stock); the `PreviewSkinLine` remote takes an allowlisted line name (type and length checked, `Util/RateLimit` 1/s burst 3, `canUse`). Runs in the match place 133387545285290, in Studio; live servers only for `Config/SkinPreview.USER_IDS` (empty = nobody since skins are owned, 2026-11-20). Camera guns follow their viewer (or the spectated player; the final-kill replay wears the killer's skins through `ViewmodelController.setSubject(copy, owner)`; bots stay stock; owner in the camera model's `SkinOwnerId`), world guns follow the character holding them (server). Immutable `Weapons` stock templates and `WeaponSkins/<Line>/<Id>` variants; missing variants fall back to stock. The F7 pick is a dev tool; real skins are owned (`shared/PlayerData` `skins`) and `SkinPreviewService` publishes only owned Locker equips (fail closed). `client/Util/ChamberFlow` (started by `SkinPreviewController`): on camera guns only, drifts the two flow `Texture` layers tagged `MoltframeFlowLayer` on structural-skin chamber parts and pulses the chamber `SurfaceAppearance.Color` (`Config/SkinPreview.CHAMBER_FLOW`); world models keep the static map. Installer for geometry skins: `tools/studio/InstallMoltframeSkin.luau` (Decal -> Image id resolve).
- **Locker skins** (`shared/Locker`) saves one equipped line per gun via the Lobby's `LockerService` and DataStore `LockerV1`. Both places publish a JSON `LockerSkins` value on the player. `SkinPreview.line(player, gunId)` uses that value when the F7 preview is on Stock. Matchmaking and returns carry their join details through `TeleportData`.
- `tools/studio/InstallFlatSkin.luau`: Studio-edit installer for flat-material geometry skins (one MeshPart per material from `tools/blender/export_roblox_flat.py`, tiled pattern Textures, kept stock parts in the line finish) into `WeaponSkins/<Line>/<Gun>`; `InstallMoltframeSkin.luau` now takes `line` too.
- Whole skin lines: `tools/blender/export_skin_items_flat.py` (per item: flat FBX + `manifest_flat.json` with replaced stock prefixes, extra rig joints, the line Vandal's palette) → `tools/studio/make_flat_install_jobs.py` stages `InstallFlatSkin` + jobs in a temporary Rojo folder `src/shared/_SkinInstall` (remove with `--clean`). Knife-slot skins install as `WeaponSkins/<Line>/Knife` with attribute `SkinItem` (Fan / Blade / Dagger).
- Skin casings: `client/Util/ShellFx` throws `WeaponSkins._Casing` (CasingBody + CasingBand, Studio-owned) coloured by `shared/Config/SkinCasings` when the gun model's `SkinLine` has an entry; else the stock brass shell.
- **Slide lean** (`client/Util/SlideTilt`, 2026-11-20): one spring stepped at `RenderPriority.First` (`Juice.SLIDE` rollIn* in, rollSpeed/rollDamping out). `CameraController.setRoll` drives it; the camera roll, `Util/Crosshair` tilt (and the hit marker through `Crosshair.tilt()`), the `ScopeOverlay` reticle and the viewmodel cant (`VM.SLIDE_CANT`, in `ViewmodelController` at the root) all read `SlideTilt.amount()`, so they stay in the same frame.
- Gun clips (`client/Util/GunAnimator`, viewmodel and third-person): a monotone cubic (PCHIP) between the 24 fps keys; bones whose Fire clip starts off the built pose rest there (the Marshal hammer). Scoped guns fade `ScopeLens` early in the aim (`VM.SCOPE_LENS`). Re-key one gun's clips headless with `tools/blender/rekey_clips.py`.
- Hiding viewmodel parts: `client/Util/LocalHide.set(part, value)` sets `LocalTransparencyModifier` on the part **and its Textures/Decals** (skin patterns); used by `ViewmodelController` (scope hide, mags, carried rounds, props, ADS fade), `ViewmodelHeldMods`, `WeaponController` (own third-person gun). `MagDrop` fades a dropped mag's Textures with it.
- Skin export checks: `tools/blender/export_roblox_flat.py` keeps `*Sight*` objects as `SK_<Bone>_Sight_NN` parts (the ADS occluder fade skips names with "Sight") and lifts flush coplanar faces (`resolve_coplanar`, 0.004 studs) and splits self-crossing faces (`fix_crossed_faces`). `tools/blender/check_flat_export.py` re-imports exported FBXs and renders them one-sided on magenta (what Studio draws). Shell-kit outlines use `model_vandal_shell_base.convex_hull_xz` (never Blender's `convex_hull_2d`). Pitfalls and checks: `vault/02 Art/Skins/Skin Build Pitfalls.md`.
- **Shadow Mist idle** (`Config/SkinPreview.SHADOW_MIST`, `client/Util/ShadowMistIdle`): the Studio-only RuinBlighted preview line uses 33 body motors and eight radial rear-sight motors under the Vandal Root. The flat-skin manifest owns the motor tags, emissive groups and effect anchors. `ViewmodelController` steps the effects after `GunAnimator` and before the rig solve. - **Shadow Mist ammunition** (`tools/blender/build_shadow_mist_magazine_rounds.py`, `client/Util/ShadowMistActions`, `Config/SkinCasings`). The full cartridge is part of the moving magazine. - **Ruin-Blighted expansion** (`Config/RuinBlightedPresentation`, `Config/Viewmodel`, `client/Util/ShadowMistActions`, `client/Util/RuinedReaver`). The server validates the pending windup, reach, cooldown and damage. Light slashes keep instant hit queries. [Expansion ledger](../02%20Art/Skins/RuinBlighted/Expansion%20Ledger.md)

## How to use this map
1. Name the area (e.g. "the Frost burst hurts allies") → find the rows → `Grep -n "symbol" src/...` → `Read` with `offset`/`limit`.
2. Gameplay numbers are in `src/shared/Config/*.luau`, never in the systems: grep the config first.
3. Anything touching a remote: read the owning service's handler and `Util/Validate` use, then the [Architecture](Architecture.md) shot walkthrough.
