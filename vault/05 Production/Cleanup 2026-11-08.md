## Plan
### Code
- **Shared helpers** (one copy instead of many): `shared/Util/Ease` (smooth, out, lerp, approach), `shared/Util/Fighters` (players' bodies + bots), `client/Util/BodyClone` (copy a body for death falls, replays, the victory scene, dash decoys), `CameraController.scopeFov`, `MapService.spawnCentre`.
- **Splits, no behaviour change:** `ViewmodelController` (tracks, held Mods), `WeaponService` (hit validation, damage, world gun), `EffectsController` (shells, tracers, impacts).
- **Dead code out:** the ammo-history rewind left from Rollback, `Mods/Blocks/Rewind`, `Config/Game`, unread Config keys, functions nothing calls.
- **Numbers into Config:** assist window, late-spawn wait, empty-round cap, kill depth, dev respawn, hit tolerances.
- **Stale comments:** old ability names (Overclock, Rollback, Patch Up, Launch Pad, Lag Field), "test opponent".
- **Maps at runtime:** every map model left in Workspace moves to `ServerStorage.Maps` when the server starts, so a live server holds only the loaded map (all 17 sat in the world before, ~48,000 instances).

- Commit the other sessions' finished files (upload ledger, map props, map notes) after a look.

- README: a one-screen map of where things live.
- Remove the 19 merged worktrees, `build.rbxl`, the `_field_*` intermediates.

### Vault

### Studio
