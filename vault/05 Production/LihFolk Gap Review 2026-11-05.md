# LihFolk Gap Review 2026-11-05

This review lists the LihFolk advice the game isn't using yet, ranked by how much each item would improve the game. It's read-only: nothing was changed in code or Studio.

**Scope.** Gameplay, feel, performance, security, QoL and accessibility. Maps, world art and UI look are out of scope because other sessions own them (LihFolk folders 05, 06, 14, 19, 21, 33, 44, 45, 54 and 55 were skipped).

**Method.**
- Read [Home](../00%20Home.md), [Match Flow](../01%20Design/Match%20Flow.md), [Gunplay](../01%20Design/Gunplay.md), [Bots](../01%20Design/Bots.md), [Match HUD](../01%20Design/Match%20HUD.md), [Architecture](../04%20Tech/Architecture.md) and the [Game Plan](Game%20Plan.md) schedule.
- Read the index, TL;DR and shooter-relevant notes in LihFolk folders 07, 08, 09, 10, 12, 22, 27, 32, 38, 42, 43, 47, 58 and 60.
- Checked every "missing" claim by grepping `src/`. These terms have **no hits** in the code: DataStore, AnalyticsService, spectate, recap, killcam, rematch, aim assist, scoreboard, AFK, BanAsync, tutorial, colourblind, haptics.

## Quick wins (S effort)
- **Hitbox scales** (#11): first check Game Settings → Avatar → Scale in Studio. If scales aren't locked, set them in code when the character spawns.
- **Camera comfort** (#12): one `Comfort` scale in `CameraController`, multiplied into the FLINCH, slide roll and FOV punch. Start it at 0 roll when `GuiService.ReducedMotionEnabled` is on.
- **Hold or toggle** (#13) for ADS and sprint, cleared on death, downed and draft open.
- **Ping chip** (#14) on the HUD: a rolling average, shown only when it's high by default.
- **Audio sliders** (#14) on the existing SoundGroups, with a squared curve. Session-only until #4 lands.
- **Build label** on the HUD for playtests (version or commit), so reports name the build ([Multi-Client Protocols](../LihFolk/12%20Performance%20Testing%20and%20Debugging/Multi-Client%20and%20Device%20Playtesting%20Protocols.md)).
- **Stable error messages**: keep ids and numbers out of `warn` text, and read Creator Hub → Error Report after each publish ([Crash and Error Telemetry](../LihFolk/12%20Performance%20Testing%20and%20Debugging/Crash%20and%20Error%20Telemetry.md)).
- **The Studio half of #1**: Clients and Servers with 2 players, plus the Network Simulator. It needs no code, just a session.

## Already done well (LihFolk agrees)
- **Hit registration:**
  - client-detected, server-validated hitscan;
  - the server recomputes rays from its own seed and clamps the claimed cone;
  - rewind by ping is capped at 0.6 s;
  - the head-to-hit-point and hit-to-body line-of-sight checks;
  - shot counter, cadence, ammo and reload are tracked on the server.

  This is the playbook's "professional choice" ([Shooters playbook §4](../LihFolk/10%20Game%20Design%20and%20Genres/Genre%20Playbook%20-%20Shooters%20FPS%20and%20TPS.md), [Teardown - Phantom Forces](../LihFolk/60%20High-Craft%20Game%20Teardowns/Teardown%20-%20Phantom%20Forces.md)).
- **Gun feel:** the crosshair gap equals the real cone (`HudController.setSpread`), recoil is a learnable pattern on the view, and the first shot is accurate ([Gun Feel](../LihFolk/09%20Gameplay%20Systems/Gun%20Feel%20-%20Recoil,%20Spread,%20Bloom%20and%20Headshot%20Multipliers.md)).
- **Remotes:** every handler is rate-limited and type-checked. Draft picks are checked against the offer the server stored ([Arena Rounds §5.2](../LihFolk/43%20Genre%20Systems%20End%20to%20End/Arena%20Rounds%20with%20Teams%20and%20Spectating%20End%20to%20End.md)).
- **Movement cheats:** under Server Authority the movement runs in the shared simulation, so speed and fly cheats mostly don't work ([Detecting Movement Exploits](../LihFolk/22%20Anti-Exploit%20and%20Security/Detecting%20Movement%20Exploits%20-%20Speed%20Fly%20Noclip%20Teleport.md)).
- **Round loop:**
  - the state is published as attributes with server end times;
  - `CharacterAutoLoads` is off;
  - the spawn barrier works as spawn protection;
  - a tie scores nobody.

  Sources: [Spawning Teams and Rounds](../LihFolk/09%20Gameplay%20Systems/Spawning%20Teams%20and%20Rounds.md), [Quick Respawn and Spawn Protection](../LihFolk/58%20Player%20QoL%20and%20Game%20Tweaks/Quick%20Respawn%20and%20Spawn%20Protection.md), [Arena Rounds §6](../LihFolk/43%20Genre%20Systems%20End%20to%20End/Arena%20Rounds%20with%20Teams%20and%20Spectating%20End%20to%20End.md).
- **Feedback:**
  - a predicted hit marker, with the kill confirmed by the server;
  - hurt effects play only on server events;
  - a damage direction indicator and a low-HP vignette;
  - camera feedback never turns your aim.

  Sources: [Combat Sound Design](../LihFolk/07%20Lighting%20VFX%20and%20Audio/Combat%20Sound%20Design%20and%20Feedback.md), [Screen Damage Effects](../LihFolk/07%20Lighting%20VFX%20and%20Audio/Screen%20Damage%20Effects%20-%20Hit%20Flash,%20Low-Health%20Vignette%20and%20Blur.md).
- **Pooling:** VFX and audio voices are pooled, and pose clips are preloaded ([Juice on a Budget](../LihFolk/47%20Game%20Feel%20and%20Juice/Juice%20on%20a%20Budget%20-%20Mobile%20and%20Low-End.md)).
- **Ability HUD:** charges and cooldown sweeps on the ability slots ([Making Numbers Feel Good](../LihFolk/58%20Player%20QoL%20and%20Game%20Tweaks/Making%20Numbers%20Feel%20Good%20-%20Cooldowns%20Buffering%20and%20Coyote%20Time.md)).
- **Bots:** reaction floors, aim error, fair misses and a hit budget per target ([AI Difficulty Tuning](../LihFolk/09%20Gameplay%20Systems/AI%20Difficulty%20Tuning%20-%20Reaction%20Time,%20Aim%20Error%20and%20Fair%20Misses.md)).
