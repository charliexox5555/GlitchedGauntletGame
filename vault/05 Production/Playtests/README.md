# Playtests

One note per playtest, review or feedback round (template: `Templates/Playtest.md`), named `YYYY-MM-DD <what was tested>.md` (e.g. `2026-11-07 Match Revamp Phase A.md`). Each note says how it was run, a results table, what wasn't tested, and a short "what to test (user)" list. Bugs found go in [Bugs & Ideas](../Bugs%20%26%20Ideas.md); the plan or design note the playtest belongs to links to it. List the newest ones in `vault/INDEX.md`.
